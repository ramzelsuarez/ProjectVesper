# Project Vesper

Project Vesper is an Unreal Engine 5.7 C++ action RPG prototype focused on gameplay programming, combat systems, and Blueprint/C++ integration.

Built as a gameplay programming portfolio project, it explores core action game mechanics including melee combat, stamina-based movement, enemy interactions, UI systems, and cinematic gameplay presentation.

## Features

- Third-person melee combat
- Sprinting, dodge, and stamina systems
- Enhanced Input integration
- Enemy combat behavior
- HUD & pickup systems
- Weapon equip/unequip system
- Blueprint + C++ workflow
- Cinematic main menu transition

## Tech Stack

- Unreal Engine 5.7
- C++
- Unreal Engine Blueprints
- Niagara VFX
- Git & GitHub

## Status

Currently in active development.
